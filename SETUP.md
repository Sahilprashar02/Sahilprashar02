# Setup

1. Create a **public** repository named exactly `Sahilprashar02`.
2. Put this repository's `README.md`, `assets/`, and `.github/` folders in it.
3. Commit/push to the `main` branch.
4. In GitHub: **Settings → Actions → General → Workflow permissions**, make sure workflows can write repository contents.
5. Open **Actions → Generate Contribution Snake → Run workflow** once.
6. After the first successful run, the snake files will be published to the `github-snake` branch.
7. The README already points at the local snake path; change those two paths to the raw `github-snake` branch URLs if GitHub does not render branch-local assets as expected.

## Important
The profile repository must be public and have the same name as the GitHub username.
